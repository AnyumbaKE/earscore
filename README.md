# EarScore
EarScore is an innovative Flutter application designed to strengthen listening and comprehension skills through real-time auditory assessments. Users listen to audio prompts and type what they hear, improving auditory processing, accuracy, and communication confidence.

With its intuitive interface and seamless functionality, EarScore transforms how individuals interact with sound. Suitable for all age groups, the app serves as a practical tool for sharpening listening skills, tracking progress, and capturing insights in real time. Whether for personal development, therapy support, or educational use, EarScore empowers users to become more attentive and effective listeners in an engaging, supportive environment.


# Features
- User Authentication: Secure signup, login, and password reset via OTP using Firebase Authentication.

- User Dashboard: Access daily listening tests, track progress, and view assessment scores.

- Auditory Assessments: Listen to audio clips and type the correct words to earn points and improve accuracy.

- Real-Time Feedback: Instant scoring and feedback to help users improve their listening ability.

- Admin Dashboard: Manage users, assign roles (add/remove admins), upload/listen to audio tests, and view user performance analytics.

- Progress Tracking: Historical visualization of performance trends over time.

- User Profile Management: Update personal details and manage settings.

- Secure Data Storage: Encrypted storage of user data and assessment results using Firebase.

- Notifications: Real-time alerts for new tests, achievements, or admin updates.

# Tech Stack
- Frontend: Flutter (Dart)
- Backend: Firebase

# Getting Started
Prerequisites
- Flutter SDK installed.
- A Firebase project set up. Guide.
- Android Studio, Visual Studio Code, or any preferred IDE.

# Installation
```
Clone this repository:

git clone https://github.com/AnyumbaKE/earscore.git

cd earscore
```
# Install dependencies:
```
flutter pub get
Configure Firebase:

Add your google-services.json (for Android) and GoogleService-Info.plist (for iOS) to the respective directories.
Enable required Firebase services in the Firebase Console.
```
# Run the app:
```flutter run```
